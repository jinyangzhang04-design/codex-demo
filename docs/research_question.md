# 研究问题与范围（v0.1）

## 课题名称

基于 AIDD 垂类大模型的小分子药物分子性质预测与候选分子筛选

本课题中的“AIDD 垂类大模型”在两个月项目周期内落地为：使用已有的预训练分子编码器或分子基础模型，并在多任务性质预测数据上进行轻量微调。项目不从零训练通用分子大模型。

## 核心问题

在 scaffold split 和标签稀疏条件下，AIDD 预训练分子表征结合多任务学习，是否比 ECFP 基线和单任务模型具有更好的外部泛化能力？

## 任务范围

| 数据集 | 任务类型 | 目标 | 指标 |
|---|---|---|---|
| ESOL | 回归 | 水溶解度 | RMSE、MAE、R² |
| FreeSolv | 回归 | 溶剂化自由能 | RMSE、MAE、R² |
| BBBP | 二分类 | 血脑屏障渗透性 | ROC-AUC、PR-AUC、F1 |
| ClinTox | 二分类 | 临床毒性 | ROC-AUC、PR-AUC、F1 |

数据版本、下载地址、样本数和审计结果以 `data/dataset_manifest.csv` 为准；在下载前不假设样本数或标签语义完全一致。

## 对比实验

1. ECFP + Random Forest：传统基线。
2. ECFP + MLP 单任务：表示学习基线。
3. ECFP + MLP 多任务：多任务基线，使用缺失标签掩码。
4. 预训练分子表征 + 多任务预测头：主要方法；若计算资源不足，使用冻结编码器或轻量适配层。

所有主要结果使用 scaffold split，并报告多个随机种子的均值和标准差；random split 只作为辅助对照。

## 研究边界

没有明确靶点活性标签时，系统输出称为“多目标成药性筛选”或“ADMET-aware 候选优选”，不宣称发现靶点活性分子。真正的靶点虚拟筛选需要另外指定靶点和活性数据。
