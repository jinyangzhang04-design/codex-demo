# 本周项目汇报稿

## 一、课题与目标

课题名称是“基于 AIDD 垂类大模型的小分子药物分子性质预测与候选分子筛选”。项目周期约两个月，目标是完成一个可复现的分子性质预测和候选分子优选原型，并形成实验报告和论文初稿。

本项目将 AIDD 垂类大模型具体落地为已有预训练分子编码器的使用和轻量微调，而不是在两个月内从零训练通用大模型。

## 二、本周完成的工作

### 1. 明确研究问题

确定核心问题：在 scaffold split 和标签稀疏条件下，预训练分子表征结合多任务学习，是否比传统 ECFP 基线和单任务模型有更好的泛化能力。

### 2. 确定首批实验任务

计划使用四个公开分子性质任务：

- ESOL：水溶解度回归；
- FreeSolv：溶剂化自由能回归；
- BBBP：血脑屏障渗透性分类；
- ClinTox：临床毒性分类。

### 3. 设计实验协议

已经确定：

- 使用 RDKit 进行 SMILES 标准化和合法性检查；
- 按 canonical SMILES 去重；
- 保留缺失标签掩码；
- 使用 scaffold split，避免相似骨架同时出现在训练集和测试集；
- 回归任务使用 RMSE、MAE、R²；
- 分类任务使用 ROC-AUC、PR-AUC、F1；
- 通过多个随机种子报告均值和标准差。

### 4. 完成项目原型

仓库中已经有一个可运行原型，包括：

- SMILES 标准化；
- Morgan 指纹和物化描述符提取；
- 多输出随机森林基线；
- 候选分子批量预测和排序；
- 一个简单 Web 页面用于输入 SMILES 和查看结果。

### 5. 完成数据审计工具

新增数据清单和审计脚本，可以统计：

- 总样本数；
- 合法和非法 SMILES 数量；
- canonical SMILES 去重后的分子数；
- 各任务缺失标签数量；
- 标签列的数据类型。

## 三、当前阶段成果

目前已经完成研究范围、数据格式、实验协议和代码骨架。原型可以在示例数据上完成训练和候选分子排序，数据审计脚本也已经通过示例验证。

需要说明的是，示例数据只用于验证流程，不能作为论文实验结果。真实公开数据集的下载和正式实验将在下一阶段完成。

## 四、当前问题

真实数据下载受到当前云环境网络策略限制，四个数据集还没有完成正式审计。因此目前还不能报告真实数据上的模型指标，也不能宣称候选筛选效果已经验证。

另外，真正的靶点虚拟筛选还需要明确靶点和活性标签。当前项目先称为“候选分子筛选”或“多目标成药性筛选”。

## 五、下周计划

1. 获取并核对 ESOL、FreeSolv、BBBP 和 ClinTox 数据；
2. 生成第一份真实数据审计报告；

- 第 8 周：系统整理、报告和论文初稿。
