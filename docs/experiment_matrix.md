# 第一周冻结的实验矩阵（v1.0）

## 划分规则

| 实验 | 划分 | 用途 |
|---|---|---|
| 单任务 Random Forest / MLP | 任务独立 scaffold split | 为每个任务提供足够的测试样本和可解释基线 |
| 多任务模型主结果 | 联合 scaffold split | 所有标签共享同一分子级 holdout，避免跨任务分子泄漏 |
| random split | 仅辅助实验 | 量化随机切分相对 scaffold split 的乐观偏差 |

联合 scaffold split 的 FreeSolv 测试标签较少，因此单独报告样本数和置信区间；不能把它与任务独立 split 的结果直接混为一个结论。

## 模型矩阵

| 编号 | 输入 | 学习方式 | 作用 |
|---|---|---|---|
| B1 | ECFP + 物化描述符 | Random Forest 单任务 | 传统基线 |
| B2 | ECFP + 物化描述符 | MLP 单任务 | 神经网络基线 |
| B3 | ECFP + 物化描述符 | 掩码多任务 MLP | 多任务基线 |
| M1 | 预训练 SMILES/分子编码器 | 冻结编码器 + 任务头 | 参数高效基线 |
| M2 | 预训练 SMILES/分子编码器 | 轻量微调 + 掩码多任务损失 | 主要方法候选 |
| M3 | M2 | 任务平衡或不确定性加权 | 改进方法候选，需先做文献核对 |

## 指标矩阵

- 回归：RMSE、MAE、R²，附测试样本数和 bootstrap 95% 置信区间；
- 分类：ROC-AUC、PR-AUC、验证集选择阈值后的 F1、Brier/ECE；
- 泛化：random split 与 scaffold split 的差值；
- 稳定性：至少 3 个随机种子，报告均值和标准差；
- 筛选：若有活性标签，报告 Top-k 命中率和 enrichment；只有性质标签时报告多目标优选结果，不宣称靶点命中。

## 冻结条件

测试集只用于最终一次报告；阈值、早停、超参数和模型选择全部使用训练集与 validation split。每次实验保存配置、随机种子、数据校验值和代码提交号。
