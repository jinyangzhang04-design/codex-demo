# 两个月研究与交付计划

## 当前阶段判断

四个数据集统一后有 4,526 个唯一分子，但任务之间的共同分子很少：ESOL 与 FreeSolv 有 340 个共同分子，ESOL 与 BBBP 有 93 个，BBBP 与 ClinTox 有 202 个，四个任务全部有标签的分子只有 4 个。因此多任务学习的主要证据应来自共享分子表征和跨任务迁移，不能表述为“每个分子同时观测了四个性质”。

当前首要工作是完成泄漏审计并冻结实验协议，然后再扩大模型规模。

## 第 1 周：实验设计冻结

- 固定数据源提交号、原始文件校验值和标准化代码；
- 统计任务之间的分子重叠和标签分布；
- 明确单任务 scaffold split 与多任务全局 holdout 的使用方式；
- 固定模型、指标、随机种子和结果表格式；
- 完成文献矩阵，核对预训练分子模型和多任务 ADMET 方法的已有工作。

## 第 2—3 周：可靠基线

- 完成 ECFP + Random Forest、ECFP + 单任务 MLP、ECFP + 掩码多任务 MLP；
- 使用 validation 选择类别阈值；
- 加入 PR-AUC、校准、Bootstrap 置信区间和错误案例；
- 对比 random split 与 scaffold split，确认数据切分对结论的影响。

## 第 4—5 周：主要模型

- 优先接入一个有公开权重和可复现加载方式的分子预训练编码器；
- 比较冻结编码器、全量微调和轻量适配三种方式；
- 以任务平衡损失或不确定性加权作为一个明确的改进变量；
- 只保留能够在多随机种子下稳定复现的改进。

## 第 6 周：筛选与可靠性

- 建立候选分子 CSV 输入和多目标排序；
- 结合性质预测、不确定性和硬性风险过滤；
- 没有靶点活性标签时，使用“多目标成药性筛选”表述；
- 若要声称靶点虚拟筛选，另选一个明确靶点活性数据集并报告 enrichment。

## 第 7—8 周：论文与交付

- 固定最终实验，不再随意更改测试集；
- 生成主表、消融表、训练曲线、校准图和筛选案例；
- 整理数据版本、配置、模型权重和运行命令；
- 完成项目报告、论文初稿和 Web 演示。

## 下一次具体任务

先完成任务重叠和跨任务泄漏审计，随后确定一份最终实验矩阵。审计通过前不继续扩展模型结构。
