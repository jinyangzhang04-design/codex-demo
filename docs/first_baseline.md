## ECFP + Random Forest（seeds=0,1,42）

| 任务 | 指标 |
|---|---|
| ESOL | RMSE 0.757±0.001，MAE 0.612±0.001，R² 0.884±0.000 |
| FreeSolv | RMSE 3.591±0.051，MAE 2.341±0.021，R² 0.567±0.012 |
| BBBP | ROC-AUC 0.893±0.001，PR-AUC 0.942±0.002，F1 0.909±0.003 |
| ClinTox CT_TOX | ROC-AUC 0.880±0.006，PR-AUC 0.268±0.007，验证集选阈值后的 F1 0.283±0.078 |

这些结果是三次随机森林训练的首轮基线，不能作为最终结论。ClinTox 的正类比例约为 5.5%，固定 0.5 阈值时 F1 为 0；使用验证集选择阈值后 F1 提升到 0.283±0.078。最终仍以 PR-AUC、校准和不确定性结果为主要依据。

## 掩码多任务 MLP 的预实验

共享编码器加任务专属头的 PyTorch MLP 已完成一次预实验。它可以在同一个网络中处理四个任务和缺失标签，但在当前 ECFP 输入上仍低于随机森林：ESOL 测试 RMSE 为 1.650，BBBP ROC-AUC 为 0.836，ClinTox PR-AUC 为 0.121。这个结果说明仅增加共享神经网络不能自动带来提升，后续需要引入预训练分子表征，并保留该模型作为负向对照。

## SMILES 领域预训练试验

为了验证完整的 AIDD 模型流程，使用训练分子集合中的 3,621 个唯一 SMILES 做了 8 轮掩码语言建模预训练，词表大小为 94，序列长度为 96；随后在四个性质任务上进行多任务微调。

当前轻量 Transformer 的结果低于 ECFP 随机森林：ESOL RMSE 为 1.750，BBBP ROC-AUC 为 0.712，ClinTox PR-AUC 为 0.054。这个结果说明仅用 3,621 个分子从头做小规模 SMILES 预训练不足以替代大规模公开分子预训练模型。论文中应把它作为本地可复现预训练基线，下一步再接入公开预训练权重或扩大无标签预训练语料。
