这些结果是单个随机种子的首轮基线，不能作为最终结论。ClinTox 的正类比例约为 5.5%，固定 0.5 阈值时 F1 为 0，下一步需要使用验证集选择阈值并报告 PR-AUC、校准和多个随机种子结果。
